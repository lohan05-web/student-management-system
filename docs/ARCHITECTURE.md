# SmartSchool Architecture (Phase 1)
- Monorepo: apps/web (React+Vite+TS), apps/mobile (Expo+RN+TS), backend (FastAPI+Python), packages/shared, docs, scripts
- DB: MySQL via SQLAlchemy 2.x + Alembic
- Auth: tokens (RBAC enforced backend)
- Realtime: WebSockets (planned)
- Tests: pytest, frontend checks later
